# Casadastraphobia

I didn't have much time to build out a full game, so treat this as a simple demo or toolbox with every mechanic. I wish I had more time but for now this is it.

## What is Casadastraphobia?

**Casadastraphobia** is the irrational fear of falling into the sky. Yeah sounds weird, it is. That's why I have chosen it!

## The Concept

The game turns that exact phobia into this:

* Open Sky = Fall Up The moment you step outside and are exposed to an open sky, gravity reverses and you start falling upward.
* Find Cover! You have to explore the world without falling up. Seek shelter under objects.
* Prototype Elements: This build includes everything needed to create the levels, fun little fans, switches and a lot more!
